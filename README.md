# 🚗 드라이브 런 (Drive Learn) - Neumorphic Audio Study App

운전 중이거나 이동, 운동, 기타 작업 중에도 **화면을 조작하지 않고 음성으로 듣기만 하며 자격증 및 기출문제를 완벽하게 학습**할 수 있는 핸즈프리 웹 애플리케이션입니다.

---

## 🌟 주요 지원 기능

### 1. 📂 다양한 기출문제 파일 추가 완벽 지원!
앱 내 우측 하단 **[📂 문제집 관리]** 메뉴에서 다양한 포맷을 바로 불러올 수 있습니다:
- **📄 PDF 파일 (`.pdf`)**: 브라우저 내장 PDF 분석기(PDF.js)가 전자문제집 CBT 등의 PDF 파일에서 문제, 4개 보기, 답안표를 100% 자동 추출하여 즉시 문제집으로 등록합니다.
- **📊 엑셀 / CSV 파일 (`.csv`)**: `문제, 보기1, 보기2, 보기3, 보기4, 정답, 해설` 열로 작성된 엑셀/CSV 파일 지원 (앱 내에서 샘플 CSV 양식 다운로드 지원).
- **📝 텍스트 파일 (`.txt`, `.md`)**: 메모장이나 워드에서 텍스트로 저장된 문제 파일 지원.
- **⚙️ JSON 파일 (`.json`)**: 구조화된 문제 목록 파일 지원.
- **📋 복사-붙여넣기**: 웹페이지나 HWP 문서에서 복사한 텍스트를 그대로 붙여넣으면 즉시 새 문제집 생성.
- **🐍 파이썬 CLI 변환기 (`pdf_to_exam.py`)**: PC 터미널에서 `py pdf_to_exam.py "시험문제.pdf"` 명령으로 일괄 변환 가능.

### 2. 🎨 소프트 뉴모피즘 (Soft UI) 디자인
- 편안하고 세련된 **음영 엠보싱 룩앤필**
- 책 표지 형태의 **상단 커버 카드 (문제 번호, 과목, 실시간 음성 웨이브 애니메이션)**
- 상세 메타 정보 카드 및 **[▶ Read]**, **[🔖 북마크]** 액션 버튼
- 부드러운 양각·음각 전환 및 차임벨 오디오 피드백

### 3. 🎧 핸즈프리 자동 음성 학습 사이클 (TTS & Chime)
- `[문제 낭독]` ➔ `[생각 시간 대기 (기본 3초)]` ➔ `[알림음 (Soft Chime)]` ➔ `[정답 발표]` ➔ `[상세 해설 낭독]` ➔ `[자동으로 다음 문제 이동]`
- 운전 핵심 모드: 보기를 생략하고 문제 본문과 정답, 핵심 해설만 빠르게 청취하여 회독 효율 극대화.

### 4. 💾 완벽한 상태 복원 (LocalStorage 실시간 저장)
- 갑자기 브라우저가 꺼지거나 앱이 종료되어도 **마지막으로 학습하던 문제 번호와 설정이 100% 자동 저장**됩니다.
- 재접속 시 이전 위치에서 즉시 복원되어 바로 이어서 학습 가능합니다.

```bash
py -m http.server 8080
```
동일 Wi-Fi의 스마트폰에서 `http://<PC의IP주소>:8080`으로 접속하여 학습할 수 있습니다.
